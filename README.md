# Dive Log

Amazfit / Zepp에서 내보낸 `.fit` 파일을 업로드하면 다이빙별로 기록을 분석해서 보여주는 프리다이빙 로그 웹앱입니다. 별도 서버나 빌드 과정 없이 정적 HTML/JS로 동작하며, 모든 데이터는 브라우저 `localStorage`에 저장됩니다.

## 주요 기능

- `.fit` 파일 업로드 (드래그 앤 드롭 / 파일 선택), 업로드 단위로 세션 생성
- 세션(업로드)별 최대수심, 총 다이빙 시간, 다이빙 횟수, 평균 심박수 등 요약
- 다이빙 목록에서 행을 클릭하면 인라인으로 차트 표시
  - 수심, 수직 속도, 심박수, 수온 차트 (드래그/터치로 크로스헤어 스크럽)
  - 다이빙별 평균/최대 하강·상승 속도
- 세션 선택 시 하단에 그날의 최대수심 / 최대 다이빙 시간 고정 표시
- 세션·다이빙 삭제, 전체 초기화

## 실행 방법

빌드 과정이 필요 없는 정적 파일이라 아무 정적 서버로 열면 됩니다.

```bash
npm run serve
```

`serve.js`가 현재 폴더를 `http://localhost:8000`에서 서빙합니다. 같은 Wi-Fi에 연결된 휴대폰 등 다른 기기에서 확인하려면 PC의 로컬 IP(예: `http://192.168.0.x:8000/index.html`)로 접속하세요.

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크 없음)
- 차트는 SVG로 직접 렌더링
- 데이터 저장은 브라우저 `localStorage`
